# 🍔 Stellar Burgers

**Stellar Burgers** — веб-приложение космической бургерной с каталогом ингредиентов, конструктором бургеров, оформлением заказов и личным кабинетом пользователя.

Проект представляет собой полноценное React-приложение с клиентским состоянием, маршрутизацией, авторизацией и интеграцией с REST API.

---

## ✨ Возможности

### 🍔 Конструктор бургеров

Пользователь может собрать собственный бургер из доступных ингредиентов:

- выбор булки;
- добавление начинок и соусов;
- изменение порядка ингредиентов;
- автоматический расчёт стоимости;
- визуальное отображение текущей сборки;
- оформление заказа после авторизации.

### 📋 Каталог ингредиентов

Приложение получает данные с API и отображает:

- список доступных ингредиентов;
- изображения и названия;
- стоимость каждого ингредиента;
- пищевую ценность;
- детальную информацию об отдельном ингредиенте.

Для навигации по каталогу используется роутинг, а интерфейс построен на переиспользуемых React-компонентах.

### 🧾 Работа с заказами

Реализована интеграция с API для:

- создания нового заказа;
- получения списка заказов пользователя;
- получения заказа по его номеру;
- отображения информации о заказе;
- работы с общей лентой заказов.

После успешного оформления пользователь получает данные созданного заказа и может продолжить работу с приложением.

### 🔐 Авторизация

В приложении реализован пользовательский authentication flow:

- регистрация;
- вход в аккаунт;
- выход из аккаунта;
- получение данных текущего пользователя;
- изменение пользовательских данных;
- восстановление пароля;
- установка нового пароля;
- автоматическое обновление access token.

Для защищённых запросов используется access token, а refresh token хранится отдельно. При истечении access token приложение выполняет обновление токена и повторяет исходный запрос.

### 👤 Личный кабинет

Авторизованный пользователь получает доступ к персональным данным и истории заказов.

Защищённые маршруты отделены от публичной части приложения, поэтому приватные операции доступны только после авторизации.
